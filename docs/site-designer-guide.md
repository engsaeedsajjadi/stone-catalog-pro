# راهنمای تصویریِ طراحی سایت (برای کاربر مبتدی)

این راهنما دقیقاً می‌گوید **هر قسمتِ پنل «طراحی سایت» کدام قسمت از سایت را تغییر می‌دهد**.

مسیر ورود: ابتدا وارد پنل مدیریت شوید (دکمه‌ی «ورود / پنل» در بالای سایت) و از منوی بالای
داشبورد روی تب **«طراحی سایت»** کلیک کنید.

> دو قانون مهم قبل از شروع:
>
> 1. بعد از هر تغییر حتماً دکمه‌ی **«ذخیره تغییرات»** (بالا یا پایین صفحه) را بزنید.
>    تا وقتی ذخیره نکنید، چیزی روی سایت عوض نمی‌شود.
> 2. تغییرات روی سایتِ اصلی همان لحظه اعمال می‌شود. قبل از ویرایش مهم، یک بار
>    از دیتابیس نسخه پشتیبان بگیرید (`npm run backup`).

## نقشه‌ی کلی: کدام بخش کجاست؟

```
┌───────────────────────────────────────────────────────────────┐
│  نوار بالای هدر (تلفن، ایمیل، شعار، شهر)   ← «برند …»          │
├───────────────────────────────────────────────────────────────┤
│  لوگو + نام کسب‌وکار │  منوی اصلی  │  جستجو، مقایسه، حساب      │
│        ← «برند …»    │  ← «منوی سایت»│                          │
├───────────────────────────────────────────────────────────────┤
│                                                               │
│                 صفحه اصلی  ← «صفحه اصلی»                       │
│            (هر بلوک یک ردیف از این صفحه است)                  │
│                                                               │
├───────────────────────────────────────────────────────────────┤
│   ستون ۱          │     ستون ۲        │     ستون ۳             │
│   نام و شعار      │  دسترسی سریع      │  اطلاعات تماس          │
│   ← «برند …»      │  ← «منوی سایت»    │  ← «برند …»            │
│   متن فوتر ← «فوتر»                                           │
└───────────────────────────────────────────────────────────────┘
         عنوان تب مرورگر و توضیحات گوگل ← «SEO و شبکه‌های اجتماعی»
         رنگ دکمه‌ها و پس‌زمینه‌ها      ← «رنگ و ظاهر»
```

## ۱) برند و اطلاعات کسب‌وکار

**کجا دیده می‌شود:** نوار بالای هدر، لوگو و نام کنار آن، بخش «اطلاعات تماس» در فوتر،
عنوانِ بلوک بالای صفحه اصلی (اگر برای بلوک عنوانی ننویسید)، بلوک تماس، و آیکون سایت (favicon).

| فیلد در پنل | اثر روی سایت |
| --- | --- |
| نام کسب‌وکار فارسی / انگلیسی | نام کنار لوگو در هدر و نام برند در فوتر. با تغییر زبان سایت، نسخه‌ی همان زبان نمایش داده می‌شود. |
| شعار فارسی / انگلیسی | زیرِ نام در هدر (سمت چپ نوار بالا)، و به عنوان زیرعنوانِ بلوک بالای صفحه اصلی اگر خودتان چیزی ننویسید. |
| لوگو | تصویرِ گرد کنار نام در هدر و آیکون سایت در تب مرورگر (اگر favicon جداگانه نگذارید). |
| تلفن | نوار بالای هدر (با کلیک، تماس برقرار می‌شود) و فوتر و بلوک تماس. |
| ایمیل | نوار بالای هدر و فوتر و بلوک تماس. |
| واتساپ | در فوتر و جاهایی که دکمه‌ی واتساپ وجود دارد. |
| شهر / کشور / آدرس | سمت چپ نوار بالای هدر و فوتر. |
| ساعات کاری | در بخش‌هایی که ساعات کاری نمایش داده می‌شود. |
| اینستاگرام، تلگرام، یوتیوب، لینکدین | آیکون‌های شبکه‌های اجتماعی در پایینِ فوتر (هر کدام را خالی بگذارید، نمایش داده نمی‌شود). |
| واتساپ | آیکون واتساپ در فوتر و دکمه‌ی «گفتگو در واتساپ» در بلوک تماس (شماره را می‌توان با یا بدون `https://wa.me/` نوشت). |
| لینک نقشه | لینک نقشه در صفحه/بخش تماس. |

> نکته: اگر تلفن، ایمیل، شعار و شهر را خالی بگذارید، **نوار بالای هدر کاملاً حذف می‌شود**
> (به‌جای آن اطلاعات ساختگی نشان داده نمی‌شود).

## ۲) رنگ و ظاهر

**کجا دیده می‌شود:** کل سایت — رنگ دکمه‌ها، پس‌زمینه‌ی بخش‌ها، رنگ متن، گردیِ گوشه‌ی کارت‌ها،
فونت و حالت روشن/تاریک.

| فیلد در پنل | اثر روی سایت |
| --- | --- |
| رنگ اصلی (`primary`) | رنگ پس‌زمینه‌ی دکمه‌های اصلی، نوارها و هدرِ صفحات داخلی |
| رنگ تیره / فرعی (`secondary`) | پس‌زمینه‌ی بخش‌های تیره و گرادیان‌ها |
| رنگ تأکیدی (`accent`) | رنگ طلاییِ عنوان‌های کوچک، آیکون‌ها و دکمه‌های شاخص |
| پس‌زمینه / رنگ متن / پس‌زمینه فرعی | رنگ زمینه‌ی سایت و رنگ نوشته‌ها |
| گردی گوشه‌ها (`radius`) | میزان گردیِ کارت‌ها و باکس‌ها (۰ = گوشه‌ی تیز) |
| فونت | فونت سراسری سایت |
| سبک کارت / سبک دکمه | ظاهر کارت‌ها (ساده / حاشیه‌دار / برجسته) و دکمه‌ها (گرد / کپسولی / مربعی) |

> رنگ‌ها را با کد هگز وارد کنید، مثلاً `#111827`. قبل از ذخیره، یک بار سایت را رفرش کنید تا
> نتیجه را درست ببینید.

## ۳) منوی سایت

**کجا دیده می‌شود:** منوی اصلیِ هدر (نسخه‌ی دسکتاپ **و** منوی همبرگری موبایل) و
بخش «دسترسی سریع» در فوتر.

هر آیتم سه چیز دارد:

- **عنوان**: متنی که کاربر می‌بیند (مثل «کاتالوگ سنگ»)
- **آدرس (href)**: مقصد کلیک. مقادیر مجاز:
  - `/` → صفحه اصلی
  - `/catalog` → کاتالوگ
  - `/about` → درباره ما
  - `/contact` → تماس با ما
  - `/export` → محصولات صادراتی
  - یا یک لینک کامل بیرونی مثل `https://example.com` (در تب جدید باز می‌شود)
- **فعال/غیرفعال و ترتیب**: با سوییچِ فعال، آیتم را مخفی کنید؛ با فلش‌های بالا/پایین جابه‌جا کنید.

> اگر هیچ آیتمی نسازید یا همه را غیرفعال کنید، منوی پیش‌فرض برنامه
> (صفحه اصلی، کاتالوگ، صادرات، درباره ما، تماس با ما) نمایش داده می‌شود.

## ۴) صفحه اصلی (مهم‌ترین بخش)

صفحه اصلی از **بلوک** ساخته می‌شود؛ هر بلوک یک «ردیف» یا «بخش» کامل از صفحه است
(مثلِ بالای صفحه، محصولات ویژه، پیشنهاد ویژه و …).

### کارهایی که می‌توانید با بلوک‌ها بکنید

| عمل | چطور |
| --- | --- |
| افزودن بلوک | از فهرستِ نوع بلوک (بالای لیست) روی نوع مورد نظر کلیک کنید |
| حذف | آیکون سطل زباله روی کارتِ بلوک |
| جابه‌جایی | فلش بالا/پایین روی کارتِ بلوک (همان ترتیب در سایت) |
| مخفی کردن موقت | سوییچ «فعال» را خاموش کنید (بلوک حذف نمی‌شود، فقط نمایش داده نمی‌شود) |
| ویرایش محتوا | فیلدهای داخل کارتِ بلوک |

هر بلوک دو فیلدِ مشترک دارد:
- **عنوان بلوک**: تیترِ آن بخش
- **زیرعنوان بلوک**: خطِ کوچکِ طلاییِ بالای تیتر (در محصولات و دسته‌بندی‌ها)

### انواع بلوک و خروجی هر کدام

| نوع بلوک | چه چیزی روی سایت می‌سازد | تنظیمات اختصاصی |
| --- | --- | --- |
| **بالای صفحه (hero)** | بخش بزرگِ بالای صفحه با پس‌زمینه‌ی تیره، تیتر بزرگ، دکمه و جعبه‌ی جستجو | چند **اسلاید**: تصویر، برچسب، عنوان، زیرعنوان، متن و لینک دکمه برای هر اسلاید؛ ارتفاع (تمام صفحه/بزرگ/متوسط)؛ زمان چرخش اسلاید؛ نمایش یا عدم نمایش جستجو |
| **محصولات** | یک ردیف کارت محصول با دکمه‌ی «مشاهده همه» | منبع: ویژه / جدیدترین / پرفروش / صادراتی / همه؛ تعداد محصول؛ پس‌زمینه تیره یا روشن |
| **دسته‌بندی‌ها** | شبکه‌ای از دسته‌بندی‌های واقعیِ کاتالوگ | نوع نمایش (شبکه‌ای یا لیستی)؛ تعداد؛ نمایش تصویر |
| **ویژگی‌ها** | کارت‌های مزیت (مثل «ارسال سریع») با آیکون | آیتم‌ها (آیکون، عنوان، توضیح) با دکمه‌ی افزودن/حذف/جابه‌جایی؛ تعداد ستون |
| **آمار** | ردیف تیره با عددهای شاخص | آیتم‌ها (مقدار مثل «۲۵۰+»، برچسب، توضیح کوتاه) |
| **نظرات مشتریان** | کارت‌های نظر با ستاره | آیتم‌ها (نام، سمت/شرکت، متن نظر، امتیاز ۰ تا ۵) |
| **گالری** | شبکه‌ای از تصاویر | تصاویر (آپلود) و تعداد ستون |
| **متن آزاد** | یک پاراگرافِ ساده‌ی وسط‌چین | متن، تراز (وسط/راست)، پس‌زمینه (ساده/ملایم/تیره) |
| **تصویر + متن** | دو ستونه: تصویر یک طرف، متن طرف دیگر (مناسب معرفی کارخانه) | تصویر، متن، جای تصویر (راست یا چپ)، متن و لینک دکمه |
| **دعوت به اقدام (CTA)** | یک نوار تیره و بزرگ با تیتر و دکمه | متن، متن و لینک دکمه، تصویر پس‌زمینه، تراز متن |
| **تماس** | اطلاعات تماس + فرم پیام | متن معرفی، نمایش فرم. تلفن، ایمیل، آدرس و ساعات کاری به‌طور خودکار از بخش «برند» می‌آیند و اگر واتساپ یا لینک نقشه تنظیم شده باشد، دکمه‌های «گفتگو در واتساپ» و «مشاهده روی نقشه» هم اضافه می‌شوند |
| **فاصله‌گذار** | فقط یک فضای خالی بین دو بخش | ارتفاع به پیکسل |

> **نکته‌ی مهم:** بلوکی که محتوایش خالی باشد، روی سایت چیزی نشان نمی‌دهد.
> پس اگر بلافاصله بعد از افزودن چیزی ندیدید، یعنی باید محتوایش را پر کنید
> (مثلاً برای «ویژگی‌ها» باید حداقل یک آیتم بسازید).

### ترتیب پیش‌فرض صفحه اصلی

اگر هیچ بلوکی نساخته باشید، سایت همین ترتیب را نشان می‌دهد و شما آن را ویرایش می‌کنید:

```
۱. بالای صفحه (hero)        ← عنوان و شعار از بخش «برند»، به‌علاوه جستجو
۲. دسته‌بندی سنگ‌ها
۳. محصولات ویژه             ← ۸ محصولِ ویژه‌ی واقعی
۴. جدیدترین سنگ‌ها          ← ۸ محصولِ جدید
۵. دعوت به اقدام (CTA)      ← دکمه‌ی «مشاهده کاتالوگ»
```

هیچ محتوای ساختگی (نام سنگ، آمار فروش، شماره تلفن نمونه) در این پیش‌فرض‌ها وجود ندارد؛
هرچه می‌بینید یا از کاتالوگ واقعی می‌آید یا خودتان می‌نویسید.

## ۵) صفحه «درباره ما»

همان سیستمِ بلوکِ صفحه اصلی است، با یک هدرِ رنگی که عنوانش از **عنوانِ صفحه** و
زیرعنوانش از **شعار برند** می‌آید. اگر بلوکی نسازید، پیام
«این صفحه هنوز توسط مدیر سایت تکمیل نشده است» نمایش داده می‌شود.

## ۶) صفحه «تماس با ما»

اگر بلوکی بسازید، **بالای فرم تماس** نمایش داده می‌شود؛ فرم تماس خودش همیشه هست و
پیام‌ها را به پنل مدیریت می‌فرستد.

## ۷) فوتر

**کجا دیده می‌شود:** پایینِ همه‌ی صفحات.

| فیلد | اثر |
| --- | --- |
| متن فوتر | پاراگرافِ زیرِ نام برند در ستون اول |
| کپی‌رایت | در صورت استفاده، در خط پایانی فوتر |

نام برند، شعار و اطلاعات تماسِ فوتر به‌طور خودکار از بخش **«برند و اطلاعات کسب‌وکار»**
خوانده می‌شود.

---

## ۸) SEO و شبکه‌های اجتماعی

**کجا دیده می‌شود:** عنوانِ تب مرورگر، توضیحاتی که گوگل نشان می‌دهد، تصویری که هنگام
اشتراک‌گذاری لینک در واتساپ/تلگرام/اینستاگرام دیده می‌شود.

| فیلد | اثر |
| --- | --- |
| عنوان سراسری | عنوان تب مرورگر (اگر خالی باشد: نام برند) |
| توضیحات متا | توضیح زیرِ لینک سایت در نتایج گوگل |
| کلمات کلیدی | کلمات کلیدی (با کاما جدا شود) |
| تصویر Open Graph (og) | تصویرِ پیش‌نمایش هنگام اشتراک‌گذاری لینک |
| Canonical URL | آدرسِ رسمی صفحه (برای جلوگیری از محتوای تکراری) |
| Twitter/X Handle | نام کاربری شبکه‌ی اجتماعی ایکس |

---

## چطور نتیجه را ببینیم؟

1. تغییر را انجام دهید → **ذخیره تغییرات**.
2. سایت را در یک تب دیگر باز کنید و **F5** بزنید (یا Ctrl+F5 برای پاک کردن کش).
3. اگر تغییر را ندیدید:
   - مطمئن شوید بلوک **فعال** است،
   - و محتوایش خالی نیست (مثلاً بلوک ویژگی‌ها بدون آیتم چیزی نشان نمی‌دهد)،
   - و مرورگر را سخت‌رفرش کرده‌اید.

## اشتباهات رایج

| مشکل | علت احتمالی |
| --- | --- |
| بلوک را ساختم ولی روی سایت نیست | بلوک غیرفعال است یا محتوایش خالی است |
| محصولات در بلوک «محصولات» نمی‌آیند | هیچ محصولی با آن منبع (مثلاً «ویژه») در کاتالوگ ثبت نشده است |
| تغییرات لوگو اعمال نشد | تصاویر باید از دکمه‌ی آپلود بارگذاری شوند؛ لینک مستقیم کافی نیست |
| آیکون شبکه‌های اجتماعی در فوتر نیست | آدرس شبکه را در بخش «برند» کامل وارد کنید (مثلاً `https://instagram.com/yourname`) |
| رنگ‌ها عوض نشد | کد رنگ را با `#` و به صورت هگز وارد کنید (مثل `#d4a72c`) |
| منو تغییر نکرد | آدرس آیتم باید یکی از `/`، `/catalog`، `/about`، `/contact` یا `/export` باشد |
